# Dubai Deal Sniper

Production-сервис поиска недооценённых автомобилей с фиксированной ценой в ОАЭ. Система собирает объявления, подтверждает цену на detail page, объединяет дубли, строит рынок по актуальным аналогам, рассчитывает расходы и публикует только экономически подходящие сигналы.

Недвижимость, аукционы и автоматическая покупка исключены.

## Пользовательские интерфейсы

- Telegram-бот: персональный поиск, сохранённые запросы, избранное и статусы.
- Free Telegram-канал: сокращённые teaser-сигналы без цены, ссылки и финансовых показателей.
- Pro Telegram-канал: полная проверяемая карточка сделки.
- Telegram Mini App: лента, фильтры, избранное и действия.
- Admin Web: полноценный Control Center с разделами Dashboard, Sources, Runs,
  Listings, Decisions, Publications, Users, Revenue, Errors и Settings.
- WhatsApp Business Cloud API: только индивидуальная opt-in доставка; без credentials отключён.

## Источники

Активные адаптеры: DubiCars, CarSwitch, Cars24 UAE и OpenSooq UAE. Источник можно включить или выключить без удаления истории. В Admin Web можно добавить HTTPS JSON feed после обязательного test fetch; обычный новый marketplace требует отдельного адаптера. Ошибка источника не заменяется mock-данными.

Следующее утверждаемое расширение — массовый сбор из чужих публичных Telegram-каналов и групп через отдельный MTProto Source Collector. Он включает автоматический Discovery, backfill sample, quality report и ручное включение источника. Это пока документация, а не заявленная работающая production-функция; подробности находятся в `docs/TELEGRAM_SOURCES_PLAN.md`. Telegram-цена считается `seller_stated` и не подменяет verified marketplace evidence.

## Как принимается решение

1. Коллектор сохраняет raw snapshot до разбора.
2. Новая версия получает стабильный `listing_id + content_hash`.
3. Цена обязательно повторно подтверждается на странице объявления.
4. Аналоги дедуплицируются и проверяются на свежесть.
5. Детерминированные движки рассчитывают рынок, расходы, прибыль, ROI и риск.
6. В Pro попадают только актуальные `CONTACT`/`INSPECT`, прошедшие пользовательские и финансовые фильтры.

LLM не задаёт цену, расходы, прибыль, ROI или итоговое действие.

## Локальная проверка

Требования: Windows 11, PowerShell, Python 3.11.

```powershell
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
Copy-Item -LiteralPath .env.example -Destination .env
python main.py scan --source dubicars
```

Для long polling задайте локально `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USER_IDS` и `DELIVERY_ENABLED=true`, затем:

```powershell
python main.py bot
```

Production использует webhook, Cloud Run и Secret Manager; локальный компьютер для работы сервиса не нужен.

## Интерфейс бота

Основной интерфейс — кнопка **Open application** в меню Telegram. В Mini App доступны:

- сделки, прошедшие проверку цены и финансовые фильтры;
- создание и остановка персональных подборов обычным текстом;
- избранные автомобили;
- бюджет, минимальная прибыль, ROI, марки, годы и пробег;
- владельцу — состояние проекта и включение/выключение источников кнопками.

Главная Mini App показывает объём собранного и проанализированного рынка, число объектов с аналогами и реальное количество инвестиционных сделок. Вкладка **Market / Рынок** содержит автомобили с подтверждённой фиксированной ценой и аналогами, но явно отделяет их от прибыльных сигналов.

Пользовательский кабинет и панель оператора разделены. Пользовательская Mini App доступна через `/app.html` и не содержит административных функций. Desktop-first панель оператора открывается в обычном браузере по `/admin.html`, использует Firebase email/password authentication и допускает административные операции только для адресов из `ADMIN_EMAILS`. Пароль не хранится в репозитории или конфигурации приложения; Telegram для работы самой панели не требуется.

Административный JavaScript использует защищённый API Gateway, потому что организационная политика проекта запрещает публичный Firebase Hosting rewrite в приватный Cloud Run. Каждый административный запрос дополнительно проверяется Firebase ID token и `ADMIN_EMAILS`. Допустимые браузерные origins задаются точным списком `CORS_ALLOWED_ORIGINS`; wildcard при credentialed CORS запрещён, а Hosting Preview добавляется только в staging.

Карточки автомобилей используют первую доступную фотографию объявления. Канал публикует отдельные карточки `MARKET WATCH` с фотографией, проверенной фиксированной ценой, рыночным диапазоном, источником и ссылкой. Такие карточки не выдаются за инвестиционные сделки; статус `DEAL` разрешён только после прохождения финансового и риск-фильтра.

Обычное сообщение боту вида `Toyota Land Cruiser, бюджет 180000 AED, 2020–2024, GCC` автоматически создаёт активный персональный подбор. Знание команд не требуется.

Бот также отвечает на обычные сообщения в чате. Кнопки позволяют запросить подбор автомобиля, обзор подтверждённого рынка, последние новости авторынка Дубая и открыть Mini App. Новости всегда показываются с издателем, датой и ссылкой; недоступная лента не заменяется сгенерированным текстом. Финансовые оценки по-прежнему создаются только детерминированным Deal Engine.

Личный бот открыт пользователям без предварительного внесения Telegram ID в конфигурацию. Владелецские операции всё равно требуют `TELEGRAM_ADMIN_USER_IDS`. Для чтения всех сообщений внутри отдельной Telegram-группы бот должен быть назначен администратором группы либо его Privacy Mode должен быть отключён через BotFather; для личного чата это не требуется.

## Подписка Pro

Начальная коммерческая цена — **100 AED за 30 дней**. Оплата цифрового доступа внутри Telegram выполняется нативной подпиской Telegram Stars. Кнопка `Upgrade to Pro` в боте и Mini App открывает платную ссылку приватного Pro-канала; добавление, продление и прекращение доступа выполняет Telegram.

После выпуска R7 цена AED, фактическая цена Stars, финансовые пороги и лимит публикаций управляются в браузерном Control Center: `https://avo-deal-sniper.web.app/admin.html`. Изменение сначала проходит Preview, затем требует точного подтверждения. Backend создаёт новую платную Telegram-ссылку, сохраняет неизменяемую версию конфигурации и атомарно делает её активной. История версий и rollback доступны в разделе Settings. Значения `PRO_PRICE_AED`, `PRO_PRICE_STARS` и `TELEGRAM_PRO_SUBSCRIPTION_URL` в окружении остаются только безопасным исходным fallback, если активная runtime-конфигурация ещё не создана или временно недоступна.

Каждый автомобильный teaser Free-канала должен содержать отдельный креативный англоязычный CTA и inline-кнопку подписки Pro, не раскрывая цену, ссылку, ID, рынок, прибыль или ROI. Кандидат `1ce36ff` не прошёл сквозной архитектурный аудит и не развёртывается. Повторная реализация выполняется только после утверждения корректирующего плана R6.

Slash-команды сохранены только как аварийный и диагностический интерфейс. Пользователю не требуется вводить их вручную.

Публичный продукт работает на английском языке: Telegram-бот, Mini App и канальные публикации. Язык устройства не переключает интерфейс на русский; это сохраняет единый англоязычный пользовательский путь для рынка ОАЭ.

## Google Cloud

Целевой проект: `avo-deal-sniper`. Все команды должны явно содержать `--project=avo-deal-sniper`, чтобы исключить развёртывание в другой активный gcloud project.

Инфраструктура описана в `infra/terraform`. Перед первым `terraform apply` существующие ресурсы необходимо импортировать в state; слепой apply поверх вручную созданного production запрещён.

Порядок immutable release, staging rehearsal, migration, cutover и rollback приведён в [операционном регламенте](docs/OPERATIONS.md). Архитектура — в [CLOUD_ARCHITECTURE.md](docs/CLOUD_ARCHITECTURE.md), контракт продукта — в [SPEC.md](SPEC.md).

## Конфигурация и секреты

Несекретные параметры перечислены в `.env.example`. Telegram/Meta credentials хранятся в Secret Manager. `.env`, токены и персональные данные не коммитятся. `DELIVERY_ENABLED=false` является обязательным fail-closed режимом для сборки, rehearsal и миграции.
