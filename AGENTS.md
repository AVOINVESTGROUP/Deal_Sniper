# Правила разработки (AGENTS.md)

Для всех агентов, работающих с проектом **Dubai Deal Sniper**, действуют следующие строгие правила:

1. **Язык общения и документации:** Все комментарии, документация (включая коммиты и логи) и общение с пользователем ведутся строго на русском языке.
2. **Среда разработки:** Windows 11 PowerShell. Учитывать синтаксис PowerShell при работе с консолью (например, использование правильных разделителей путей, кавычек и т.д.).
3. **Чистый Python:** Код пишется под Python 3.11 с обязательным использованием type hints (аннотаций типов).
4. **Безопасность конфигурации:** Категорически запрещено коммитить или хардкодить любые API-ключи, токены или личные данные. Все параметры должны считываться из `.env`.
5. **Предотвращение дублирования:** Запросы к Gemini API должны выполняться только для новых объявлений, которые еще не были сохранены в локальной SQLite базе данных.
6. **Обновление документации:** После каждого успешно завершенного шага обязательно обновлять `docs/STEPS.md` и `AI_CONTEXT.md`.
